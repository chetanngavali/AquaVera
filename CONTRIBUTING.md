# Contributing to AquaVera

First off, thank you for considering contributing to AquaVera! Your contributions help improve the platform for farmers and sustainable water management.

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug is already reported** in the GitHub issues section.
- **Provide a clear description** of the steps to reproduce the bug.
- **Include logs and screenshots** where applicable.

### Suggesting Enhancements

- **Open a new feature request** in the issues section.
- **Explain why the enhancement is needed** and how it benefits the farming community.

### Pull Requests

1. **Fork the repository**.
2. **Create a new branch** following the naming convention:
   - `feat/feature-name` for new features.
   - `fix/bug-name` for bug fixes.
   - `docs/doc-update` for documentation changes.
3. **Write clean, documented Kotlin code**.
4. **Follow the existing MVVM architectural pattern** and Jetpack Compose best practices.
5. **Sync Gradle and ensure the project builds** before submitting.
6. **Create a Pull Request** with a detailed description of your changes.

## Coding Standards

- **Formatting**: Use the standard Kotlin style guide.
- **Commit Messages**: 
  - `feat: [description]`
  - `fix: [description]`
  - `docs: [description]`
- **Documentation**: Add KDoc comments for non-trivial functions and classes.

## Community

Join the conversation and help us grow a sustainable future for agriculture!
